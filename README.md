### 💛 Pro bono: [DWAR Foundation](https://dwar.org.in)

I'm the lead developer of DWAR Foundation's platform, built in my own time. DWAR is an NGO in Patna working on skills, education and careers for young people. I replaced its WordPress site, Google Forms and spreadsheets with **one Next.js + Firebase system**:

- **A public website** plus portals for volunteers, interns, trainers, coordinators and admins, with **6 roles** and role-based access
- **Registration and admin review**, Google sign-in, document uploads
- **Events, guest sign-up, attendance and automatic volunteer hours**
- **PDF certificates with QR codes** and public verification
- **Razorpay donations** with webhook verification, an admin CMS, CSV reports, and GitHub Actions CI

`Next.js` · `TypeScript` · `Tailwind` · `Firebase Auth / Firestore / Storage` · `Razorpay` · `pdf-lib` · 43 pages · 15 API routes
